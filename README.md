# The Line: Northbank
## 《线：北岸》

This repository stores the game design bible for The Line: Northbank / 《线：北岸》.

Project type: cinematic narrative science-fiction RPG.

Current stage: 世界观结构、第一章脚本、第二章设计、派系动机与隐藏支线整理中。

## Current Status

- Chapter 1: Outside is available at `docs/story/chapter-01-outside.md`.
- Chapter 2: Review design is available at `docs/story/chapter-02-review.md`.
- Hidden side quest notes are available at `docs/story/hidden-old-duct.md`.
- The naming system is available at `docs/naming-system.md`.
- The overall story structure is available at `docs/story-structure.md`.
- Worldbuilding notes are organized under `docs/world/`.
- The protagonist is currently only defined as an ordinary surveyor.
