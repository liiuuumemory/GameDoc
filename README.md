# The Line: Northbank
## 《线：北岸》

电影化强叙事科幻 RPG 企划。玩家扮演一名测绘员，在北岸执行临时复核，记录轨道图层、地面图层、居民经验与设施记录之间的偏差。

当前阶段：世界观结构、第一章脚本、第二章设计、派系动机与隐藏支线整理中。
