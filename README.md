# The Line: Northbank
## 《线：北岸》

This repository stores the game design bible for The Line: Northbank / 《线：北岸》.

Project type: cinematic narrative science-fiction RPG.

Current stage: worldbuilding and episode script organization.

- The overall story structure is available at `docs/story-structure.md`.
- Worldbuilding notes are organized under `docs/world/`.
- The protagonist is currently only defined as an ordinary surveyor.
