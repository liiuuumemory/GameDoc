# World Rules
## 世界观规则

## 线

线既是地理边界，也是行政边界。它不是一条能被肉眼看到的细线，而是一组由温度、设施、救援可达性、居住许可和责任归属共同构成的长期生活标准。

## 居住状态

居住状态不是即时生死判断，而是官方是否承认某处适合长期生活。状态变化会影响许可证、学校、诊所、配给、维护优先级和迁离安排。

## 图层

轨道图层提供宏观判断，地面图层来自现场复核。两者不一致时，系统首先会要求补样本、改格式、解释来源，而不是自动改变状态。

## 设施

泵房、遮光系统和低功率管线可以影响局部环境，但设施输出不等于居住保障。设施方会避免把非居住级系统登记为稳定生活来源。

## 揭示边界

第一章和第二章只表现模型偏差、旧街区异常和行政流程。下层结构、维护机和废热真相只能作为后期或真结局层面的内部设定处理。
