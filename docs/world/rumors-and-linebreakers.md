# 越线者与线外传说

## 1. 越线者的定位

越线者不是正式教会，也不是掌握真相的秘密组织。他们更像一群混杂着失去住所的人、安置失败者、阴谋论者、越界幸存者、骗子和少数真正见过异常空间的人。

他们反对“线”的垄断解释权，认为管理局把生存变成许可证，把世界缩成图层和状态。

## 2. 传说类型

### 低光传说

低光传说主要围绕低光区、旧街区、冷区边缘和旧接口。

- 有人说低光区深处有不结霜的房间。
- 有人说旧泵房之外还有亮着灯的空间。
- 有人说某些人在官方注销后仍会每月回来领药。
- 有人说在最冷的夜里，线外反而比安置点暖。

### 高光传说

高光传说主要围绕高光侧、遮光系统外和设施区。

- 有人说高光区不是全都无法进入，遮光板背后有很长的阴影空间。
- 有人说维护人员会从二号门出去，回来时衣服是干的，不像从死地回来。
- 有人说管理局把真正宽阔的地方留给上层，只让普通人挤在线上。

这些传说可以有现实来源：高光侧确实存在设施区、轮班宿舍、维护阴影和高成本防护空间。但它们不是宜居地。

### 归来者传说

归来者传说围绕有人越过线外后返回。

传说中，有人离开北岸许久后回来，说线外不是空的，说那里有路、有暖处、有不属于管理局图层的空间。后来这个人被带走，或者再也没有出现。

这些故事不应证明真相，只应说明：越线者的信仰来自一些无法被官方语言安放的经验。

## 3. 越线者与旧接口

越线者把旧风道、排热夹层、旧运输管和封堵失败的维护空腔称为“路”。这些空间不是为人设计的，也不稳定，但偶尔能让人穿过、过夜，甚至在短时间内获得一点热量。

他们说“线外不是空的”，这句话有现实根源。但他们的解释常常是错的。他们把破损接缝误认为出口，把短暂余温误认为可居住之地，把旧接口误认为被当局隐藏的道路。

## 4. 第二章中的越线者

第二章中，越线者只作为次级冲突出现，不要成为主线派系。

建议出现方式：

1. 市场街公告栏旁出现越线者传单。传单写着类似“线外并非空无一物”的话。管理局人员撕掉传单，陈玛拉认为这些传单只会让巡查变严。
2. 旧街区核查现场，有越线者煽动居民不要相信管理局，说“他们说这里不能住，是因为他们不想让你们知道线外还有地方”。
3. 七号泵房降载后，有人提出不要去管理局安置点，而是跟越线者走旧风道，去所谓“更暖的外段”。

陈玛拉可以反驳越线者：

> 你要走就自己走。别拿老人的命证明你的传单。

越线者在第二章的作用是制造社会噪音和危险诱惑，而不是提供答案。
