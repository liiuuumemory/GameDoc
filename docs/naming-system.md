## 使用规则

1. 中文正文中优先使用中文正文用名。
2. 不要在正文中反复写 “The Line（线）”“Northbank（北岸）” 这种形式。
3. 英文名主要用于标题、UI 草案、命名对照表、文件名、章节索引。
4. 中文正文应该自然、克制、现实，不要像设定集翻译腔。
5. 不要使用二游、轻小说、网文式命名。
6. 不要提前使用“黑太阳”“地底热脊”“不可测层”等会剧透真结局的词。
7. “A Place Still Warm / 仍有余温之地”只保留给真结局，不作为普通章节名或任务名。
