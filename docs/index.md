## 文档分类规划

- 章节脚本：用于存放每一章的剧情、对白、场景和任务流程。
- 世界观设定：用于存放潮汐锁定星球、晨昏线城市、灰湾、适居边界等设定。
- 角色档案：用于存放主要角色、居民、派系成员和关键 NPC。
- 地点设定：用于存放背夜泵站、中线边缘居民街、朝光检修口等区域设定。
- 系统设计：用于存放测绘、仪器读数、报告提交、选择分支等玩法说明。
- 开发记录：用于存放版本变化、设计取舍和后续 TODO。
