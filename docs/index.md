# The Line: Northbank
## 《线：北岸》Game Design Bible

这是《线：北岸》的 GitHub Pages 文档目录页，用于整理章节脚本、世界观设定、系统设计、视觉资料和制作记录。

项目类型为电影化强叙事科幻 RPG。当前阶段为世界观与章节脚本整理。主角暂时只保留为普通测绘员。

## 目录规划

| 目录 | 用途 |
|---|---|
| `story/` | 章节脚本、剧情流程、结局路线 |
