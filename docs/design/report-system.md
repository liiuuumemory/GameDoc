## 当前版本

报告系统是玩家影响剧情的主要接口。它把现场现实压缩成可提交的状态、样本、附件和说明。

## 第一章报告选项

- 维持缓冲状态。
- 暂缓状态变更。
- 上报未登记居住。
- 提交偏差附录。
- 不记名提交。

## 设计目标

- 让玩家理解“事实”进入系统之前必须被格式化。
- 让每个选项同时带来保护和代价。
- 避免单纯善恶选项。
