## 当前版本

《线：北岸》是一款电影化强叙事科幻 RPG。玩家扮演一名普通测绘员，在北岸执行临时复核，核对轨道图层与现场数据，并提交会影响居民居住状态的报告。

本仓库是项目的 game design bible，用于保存命名系统、剧情结构、世界观规则、章节脚本、系统设计、视觉方向和制作记录。

## 写作边界

- 主角暂时只保留为普通测绘员。
- 不加入家庭背景、旧事故、早年创伤或特殊身份设定。
- 管理局、设施方、安息所都不是纯反派。
- 越线者不是掌握真相的教会或秘密组织。
- 正文优先使用自然中文，不反复写英文名词加中文括号。
