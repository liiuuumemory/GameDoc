# Demo Scope
## Demo 范围

当前 playable build 聚焦第一章《线外》。

## Included

- Survey Office
- Market Street
- Old Blocks
- Gate Two
- Layer comparison
- Facility data check
- Report terminal
- Chapter ending summary

## Not Included

- Chapter 2
- Old Duct hidden route
- True ending
- Protagonist backstory
- Final art
- Full audio
- Save/load system
